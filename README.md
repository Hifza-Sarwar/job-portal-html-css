# Job Portal Website

A multi-page job portal website built using HTML5 and CSS3.

# Features
- Homepage with job categories
- Separate pages for each job category
- Apply form and Signup page
- Contact page

# Pages
index.html -Home page with all job listings
accounting.html , technology.html, marketing.html - Category Pages
apply.html - Job application form 
signup.html -User registration
contact.html -Contact form
latest.html -Latest jobs posts

# Tech Used
- HTML5
- CSS3

# How to run

Open index.html in your browser
